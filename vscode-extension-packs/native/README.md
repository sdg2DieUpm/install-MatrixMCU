# MatrixMCU: Native C/C++

Extension Pack for native C/C++ development on Linux, macOS, and WSL. It
installs the editor extensions listed in `package.json`, including C/C++ support,
CMake integration, the C/C++ Project Generator, Hex Editor, and the official
[vscode-icons](https://marketplace.visualstudio.com/items?itemName=vscode-icons-team.vscode-icons)
file icon theme. It does not install GCC, GDB, Make, CMake, or other system tools.

Install the pack manually from the VS Code **Extensions** view. For WSL,
connect to the distribution containing your development tools first, then check
which extensions are installed in **Local** and which are installed in **WSL**.

To enable the icons, run **Preferences: File Icon Theme** and select **VSCode Icons**.
