# MatrixMCU: C/C++ nativo

Extension Pack para seguir el recorrido de C nativo en Linux, macOS o WSL.
Instala las extensiones de editor listadas en `package.json`; no instala GCC,
GDB, Make, CMake ni otros programas del sistema.

Instálalo manualmente desde la vista **Extensions** de VS Code. En WSL,
selecciona primero la distribución donde se instalaron las herramientas y
comprueba en la vista de extensiones qué componentes están en **Local** y cuáles
en **WSL**.
